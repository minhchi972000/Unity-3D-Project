### Unity Import Instructions
1. Select each PNG file in Unity Project window
2. In Inspector, set:
   - Texture Type: **Sprite (2D and UI)**
   - Sprite Mode: **Multiple**
   - Pixels Per Unit: **16**
   - Filter Mode: **Point (no filter)** (preserves pixel art crispness)
   - Compression: **None**
3. Open Sprite Editor
4. Click **Slice** → Type: **Grid By Cell Size** → Size: 16x16
5. Click **Apply**
